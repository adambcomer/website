About Me

Experience, skills, and background

Software Engineer

I'm a Full-stack Software Engineer with a broad background in Backend, Frontend, and Infrastructure development. Currently, I work as a Software Engineer III at Syniti on the core Platform Team, where I build Go microservices and the Next.js/React frontend, and am a key contributor to the Terraform and Kubernetes work our platform runs on.

Outside of work, I write Rust and Typescript in my personal projects — an LSM-Tree key-value store modeled on RocksDB, a linguistics syntax tree solver, and this website.
